# অ্যাডমিন গাইড

অ্যাপে অ্যাডমিন হিসেবে লগইন করলে নিচে **Admin** ট্যাব আসে। ওয়েব ভার্সনেও (https://tech.dropout.it) একই প্যানেল চলে, বড় স্ক্রিনে কাজ করা সহজ।

## অ্যাডমিন প্যানেলে যা আছে

|---|---|

## অ্যাডমিন আইডি (ইমেইল) আর পাসওয়ার্ড বদলানো

প্রথম অ্যাডমিন তৈরি হয় সার্ভারের `backend/.env` ফাইলের `ADMIN_EMAIL` আর `ADMIN_PASSWORD` থেকে, যখন আপনি `seed` চালান। এরপর তিনভাবে বদলাতে পারেন।

### উপায় ১: অ্যাপ থেকে (সবচেয়ে সহজ)

1. অ্যাডমিন হিসেবে লগইন করুন।
2. **Admin** ট্যাব → নিচে **System** → **Admin login & password**।
   (অথবা **Account** ট্যাব → **Login & security**।)
3. **লগইন আইডি বদলাতে:** "Login ID" বক্সে নতুন ইমেইল আর/অথবা মোবাইল লিখুন, নিচে বর্তমান পাসওয়ার্ড দিন, **Save** চাপুন।
   পরেরবার নতুন ইমেইল বা মোবাইল দিয়ে লগইন করবেন।
4. **পাসওয়ার্ড বদলাতে:** "Change password" বক্সে বর্তমান পাসওয়ার্ড, নতুন পাসওয়ার্ড (কমপক্ষে ৮ অক্ষর) দুইবার দিন, **Save** চাপুন।
   এই ফোনে লগইন থাকবে, কিন্তু অন্য সব ফোন/ব্রাউজার থেকে নিজে থেকেই লগআউট হয়ে যাবে।
5. ইমেইল বদলালে সার্ভারের `backend/.env`-এ `ADMIN_EMAIL`-ও নতুন ইমেইলে বদলে দিন। না বদলালে পরে কখনো `seed` চালালে পুরনো ইমেইলে আরেকটা অ্যাডমিন তৈরি হবে।

### উপায় ২: সার্ভার থেকে (পাসওয়ার্ড ভুলে গেলে)

সার্ভারে SSH করে প্রজেক্ট ফোল্ডারে যান, তারপর:

```bash
# শুধু পাসওয়ার্ড বদলাতে
docker compose exec api node dist/seed/admin.js --password 'NotunPassword123'

# ইমেইল আর পাসওয়ার্ড দুটোই বদলাতে
docker compose exec api node dist/seed/admin.js --email boss@tech.dropout.it --password 'NotunPassword123'

# একাধিক অ্যাডমিন থাকলে কোনটা বদলাবেন সেটা বলে দিন
docker compose exec api node dist/seed/admin.js --current old@tech.dropout.it --email new@tech.dropout.it
```

এটা অ্যাডমিনকে সব ডিভাইস থেকে লগআউট করে দেয়। এরপর নতুন তথ্য দিয়ে লগইন করুন, আর উপরের ৫ নম্বর ধাপের মতো `.env`-এ `ADMIN_EMAIL` আপডেট করুন।

### উপায় ৩: দ্বিতীয় অ্যাডমিন বানানো

অন্য কাউকে অ্যাডমিন বানাতে: সে আগে অ্যাপে সাধারণ অ্যাকাউন্ট খুলবে, তারপর আপনি **Admin → Users & roles** → তার নামের পাশে ⋮ → **Make admin**। নিজের অ্যাডমিন রোল নিজে সরানো যায় না, যাতে ভুল করে প্যানেল থেকে আটকে না যান।

## ডেমো কনটেন্ট

অ্যাপ সুন্দর দেখাতে কিছু ডেমো কোর্স, টিচার, রিভিউ আর জব রাখা যায়:

```bash
docker compose exec api node dist/seed/demo.js            # ডেমো যোগ
docker compose exec api node dist/seed/demo.js --remove   # সব ডেমো মুছে ফেলা
```

সব ডেমো অ্যাকাউন্টের ইমেইল `@demo.tech.dropout.it` দিয়ে শেষ, পাসওয়ার্ড `demo12345`। আসল টিচার আর কোর্স এলে `--remove` চালিয়ে দিন; আসল ডেটায় হাত পড়ে না।

ডেমো লেসনের ভিডিওগুলো ইন্টারনেটের পাবলিক স্যাম্পল ভিডিও। নিজের কোর্সে আসল ভিডিও আপলোড করুন (নিচে)।

## রেকর্ডেড ভিডিও আপলোড

অ্যাডমিন (**My recorded courses**) আর টিচার (**Teach** ট্যাব) একইভাবে আপলোড করেন:

1. কোর্স খুলুন → **Course details**-এ নাম, ছবি, দাম, "যা শিখবেন" ইত্যাদি দিন।
2. **Add section** দিয়ে সেকশন, প্রতিটা সেকশনে **Add lesson**।
3. প্রতিটা লেসনে **Upload video** চাপুন, ফোন/কম্পিউটার থেকে ভিডিও বেছে নিন। আপলোডের অগ্রগতি দেখাবে; শেষ হলে ভিডিওর দৈর্ঘ্য নিজে থেকেই বসে যায়।
4. অন্তত একটা লেসনকে **Make free preview** করুন, যাতে না কিনেও শিক্ষার্থীরা দেখতে পারে।
5. **Publish** (অ্যাডমিন) বা **Send for review** (টিচার)।

ভিডিও: MP4 (H.264), 720p বা 1080p ভালো। প্রতি ভিডিও সর্বোচ্চ ২ GB (`.env`-এ `MAX_VIDEO_MB` দিয়ে বদলানো যায়)। ভিডিও কোথায় জমা থাকে আর পরে Firebase-এ নেওয়ার উপায় [STORAGE.md](STORAGE.md)-এ।
